# Link Fetch

Downloads client deliveries from Dropbox, WeTransfer and Google Drive share links, unzips them and organises the files (sessions, stems, references) into a song's folder. Needs the internet for those three services only.

An add-on for AiAudioHub: get it in AiAudioHub, Explore. Namespace `jpmm-link-fetch`, version 0.1.0.
